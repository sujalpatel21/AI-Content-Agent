Content Scraper (Agent 01)

This agent leverages Apify to silently scrape high-performing social media posts from Instagram, Twitter, and YouTube based on your query. It returns raw JSON arrays containing views, likes, comments, URLs, and captions.

Status: Operational
Framework: Apify Client
Rate Limit: 1000 requests/day

🛡️
Validation Agent (Agent 02)

The Validator passes the raw scrape data through Gemini LLM to filter out noise, validate viral mechanics, cluster topics, and determine what format is currently generating the most traction.

Status: Operational
Framework: Google Gemini (2.0 Flash)
Inputs: Scraped JSON array

📝
Script Writer (Agent 03)

Takes the validated topic clusters and a predefined Voice Profile JSON. Generates a completely novel, structured script containing Visuals, Audio cues, and narration perfectly matching the target tone.

Status: Operational
Framework: Google Gemini
Instructions: "Maintain high retention pacing"

⚡
Hook Generator (Agent 04)

Reads the finalized script and generates 5 powerful hook variations (e.g., Negative, Curiosity, Benefit-driven) based on viral psychology to maximize the first 3 seconds of retention.

Status: Operational
Framework: Google Gemini
Outputs: JSON Array of Hooks
